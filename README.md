# Tutorías de Andrés Valencia

Sitio web de tutorías académicas para estudiantes de 6.º a 11.º, desarrollado con HTML, CSS y JavaScript.

## Abrir localmente
1. Descomprime la carpeta.
2. Abre `index.html` en un navegador o usa la extensión Live Server de Visual Studio Code.

## Contenido
- Presentación del docente con fotografía real en `assets/img/docente.jpg`.
- Ilustración matemática de portada y recursos visuales de las sesiones en `assets/img/`.
- Servicios, metodología, niveles y temas por grado.
- Sección “Así se desarrolla una clase”, con descripciones ilustrativas de la dinámica de las sesiones (no son testimonios de estudiantes).
- Calculadora de plan orientativo y cotización.
- Guías académicas descargables en `assets/guias/`.
- Formulario de contacto que prepara un mensaje para WhatsApp o correo.

## Personalización
- Textos, servicios, tarifas, horarios y temarios: `main.js` e `index.html`.
- Diseño y colores: `styles.css`.
- Número de WhatsApp y correo: objeto `CFG` al inicio de `main.js`.
- Fotografía del docente: `assets/img/docente.jpg`.

## Importante
El simulador de reserva y pago es únicamente una simulación: no realiza cobros ni reserva horarios. Las tarifas y la disponibilidad deben confirmarse antes de iniciar las clases. Las reseñas descriptivas de la sección de clases explican cómo puede desarrollarse una sesión; no se presentan como opiniones reales de clientes.
